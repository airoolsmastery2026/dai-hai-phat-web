# DHP SEO

Use for metadata, structured content, internal linking, service-page optimization, indexability, content briefs, and technical SEO.

## Rules

- Optimize for real customer intent and useful service information, not keyword stuffing.
- Preserve semantic heading structure and accessible content.
- Keep metadata specific to the page and business offer.
- Prefer existing Next.js metadata and project patterns.
- Do not fabricate awards, reviews, locations served, project counts, credentials, or testimonials.
- Avoid duplicate/near-duplicate pages created solely for search engines.
- Treat Core Web Vitals/performance as part of SEO work.
- For current search-engine rules or volatile SEO claims, verify primary documentation before implementation.

## Verification

Check rendered metadata/structured data where possible, inspect internal links, and run the repository quality gate for substantial code changes.
