# Claude Code project entry point

Before every task, read `.ai/MASTER_PROMPT.md` as the compact execution contract.

Before every UI task, read `DESIGN.md`, `COMPONENTS.md`, and
`.ai/UI_PROMPT.md` completely. Those files are the canonical visual and
component contract. Do not duplicate their rules in this file.

For non-trivial architecture, AI, API, CRM, data-flow, authentication, automation, pricing, or integration work, follow `AGENTS.md` and the required project docs it references.
